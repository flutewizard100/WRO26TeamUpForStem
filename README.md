# Mechanical

Base:

For the base, we disassembled a LaTrax Prerunner and used its main chassis structure. We replaced both driveshaft gears, the motor, and the servo to improve reliability, performance, and steering control.

First Layer:

Above the base, we attached a custom laser-cut MDX-40 plate using screws. This plate provides secure mounting points for the LiDAR, battery, power switch, and power distribution board, helping keep the components organized and stable.

One of our main considerations when positioning the components was ensuring that the LiDAR had enough clearance while still being low enough to detect the walls and blocks accurately. For this reason, we mounted the LiDAR on a first plate using standoffs to slightly elevating it above the other components on the same plate.

Second Layer:

To connect our second laser-cut plate, we used four standoffs to minimize the amount of space blocked from the LiDAR’s view. On this second plate, we mounted our control boards. All wires running up to the second layer are routed next to the standoffs to prevent obstruction and keep the LiDAR’s field of view clear.
